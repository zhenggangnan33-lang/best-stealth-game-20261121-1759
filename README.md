**Shadow Gallery** — a top-down stealth game. Midnight at the Meridian Gallery: steal the Ruby Idol, the Emerald Mask and the Sapphire Eye, then slip out the green exit — unseen. Four guards patrol with vision cones; walls and display cases break their sight. Sneak with Shift, toss a coin with a click to lure a guard away.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No build step, no network requests, no dependencies — plain static files under `game/`.

## Controls

- **Move:** WASD or arrow keys
- **Sneak:** hold Shift (slower, much harder to spot)
- **Toss a coin:** click anywhere (5 coins; the nearest guard walks over to look)
- **Pause:** P or Esc · **Mute:** M · **Start / restart:** Space or click

## Rules

- A guard's vision cone fills your suspicion meter; full means a chase. Break line of sight to cool down.
- If a guard touches you, you're caught. Collect all 3 artifacts, then step into the green exit to win.
- Finish unseen for a **GHOST** rating; get spotted and still escape for **SHADOW**.
